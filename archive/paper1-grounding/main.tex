% --- Float placement -----------------------------------------------------
% This paper is table-heavy: eleven floats, several in consecutive
% subsections.  With LaTeX's defaults the queue backs up and a deferred float
% can drift past the bibliography to the end of the document, which happened
% before these settings were added.  Two fixes, both needed.
%
% 1. Permit more of a page to be float and more floats per page, so the queue
%    drains instead of accumulating.
\renewcommand{\topfraction}{0.9}
\renewcommand{\bottomfraction}{0.8}
\renewcommand{\textfraction}{0.07}
\renewcommand{\floatpagefraction}{0.7}
\setcounter{topnumber}{3}
\setcounter{bottomnumber}{2}
\setcounter{totalnumber}{5}
%
% 2. placeins with [section] inserts an implicit barrier at each \section, so a
%    float can never appear before its own section heading or after the next.
%    A table that discusses one section's argument stays in that section.
