# Evaluation tasks (supplied by the owner)

Guidance section 4: the owner supplies the task descriptions and decides how many. The builder
writes the harness, not the tasks. Put one task per file here as `<task_id>.md`; the file's whole
content is the prompt given to `claude -p`. Nothing runs until the owner approves (see
`cicd/llm/eval/run_eval.py --help`).
